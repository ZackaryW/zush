# BDD coverage

Every externally observable delta scenario is traced by its `@delta-*` tag in
the five capability-owned feature roots. Scenario outlines intentionally group
closely coupled outcomes that occur during one public CLI interaction.

Pure case matrices remain focused unit obligations:

- malformed address variants and owner expansion;
- glob exclusion and namespace serialization cases;
- generated-index ordering, identity escaping, and JSON serialization;
- exact and suffix candidate combinations plus runner argv selection;
- TOML type validation, overlay precedence, and tombstone matrices;
- `str`, `int`, `float`, `bool`, and `json` cast success/failure matrices;
- shallow merge and temporary-file cleanup on exceptional paths.

Each such rule retains at least one tagged public scenario proving enforcement
through the installed CLI boundary.
